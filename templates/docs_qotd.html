Question of the Day, shortened to QOTD, posts one question to your channel every day. Each question appears in its own dedicated thread so answers stay tidy. Questions come from a large built in pool and do not repeat until the pool reshuffles.

How it works

one question a day
What Details
Schedule Posts once per day. The default time is 16:00 in the server timezone, which defaults to UTC.
Thread Every question is posted with a thread named after the date, so discussion stays attached to the question. Threads auto archive after 24 hours.
Ping role Optional. When set, the role is mentioned when the question posts, which can draw people in or route it to members who opted in.
Question pool Questions are drawn in a shuffled order per server and never repeat until every question has been used, then the pool reshuffles.
Cleanup With cleanup on, yesterday's question message and thread are removed when the new one posts, keeping the channel from piling up.

Commands

admins only

Admins only. Every QOTD command requires the Administrator permission. The fastest setup is /config auto with qotd:true, which creates the channel, creates a QOTD Ping role, and enables everything for you.

/config qotd set_channel administrator

Choose the channel where daily questions are posted. The bot checks that it can view and send messages there first.

Parameters
channel The text channel for daily questions.
/config qotd enable administrator

Turns the daily post on or off. A channel must be set first. The bot verifies it can view the channel, send and embed messages, and create and post in threads before enabling.

Parameters
enabled True to start posting, False to stop.
/config qotd set_time administrator

Set the time of day the question posts, in 24 hour format, and optionally a timezone. Changing the schedule resets today's state so the next question posts at the new time even if one already went out.

Parameters
time 24 hour HH:MM format, for example 18:30.
timezone IANA timezone such as Europe/Amsterdam. Autocompletes as you type. Defaults to UTC.
/config qotd set_role administrator

Pick the role that is mentioned when a question posts. The role must sit below the bot's highest role so it can be mentioned reliably.

Parameters
role The role to ping with the question. Use @everyone to ping the whole server.
/config qotd delete_old administrator

When enabled, the previous question's message and thread are deleted right before the next one posts. This keeps the channel to just the latest question.

Parameters
enabled True to delete old questions, False to leave them up.

Permissions for QOTD

what the bot needs

To post questions the bot needs these permissions in the QOTD channel: View Channel, Send Messages, Embed Links, Create Public Threads, and Send Messages in Threads. If one is missing, the enable command names it for you. For cleanup it also needs Manage Messages and Manage Threads.
