The AI lives on VoidWave's own hardware through Ollama. Prompts and replies are handled locally and are never sent to third party AI providers. You can talk to it anywhere the bot works: servers, DMs, and private channels.

Ways to chat

three ways in
Method How
/ai The direct command. Pass your message as the message option.
Mention Type @VoidWave followed by your message anywhere in a server.
Reply Reply to VoidWave's own message and it will respond, using the replied to message as context.

Add --stats at the end of your message to append model info to the answer: token count, generation time, and tokens per second. Works with both /ai and mentions.

Behaviour and limits

cooldowns and queues
Limit Value
Cooldown 15 seconds between AI requests per user, across both the command and message triggers.
Queue Mentions and replies go through a message queue. If the bot is busy, your request is queued and a position message tells you where you stand. The queue takes up to 10 requests. The /ai command does not queue: when the model is busy, it asks you to try again shortly.
Context Replying to a message gives the model the replied to text as context. Mentioned users and channels in your message are expanded to their names.

Commands

chat and control
/ai servers, DMs and private channels

Send a message to the model and get the reply. Usable anywhere, even in servers where automatic replies are switched off.

Parameters
message What you want to say. Required.
stats Append token count, time, and tokens per second to the reply. Optional.
hidden Show the exchange only to you. Optional.
/aitoggle servers, DMs and private channels

Turns AI replies on or off for you personally. Off by choice, on by default. When off, mentions and replies are ignored, and mentioning the bot returns a short notice instead.

Parameters
enabled True or False to set it explicitly. Leave it out to flip the current state.

Kirkify

AI face swap

The Kirkify meme, straight from Discord. Upload an image and VoidWave swaps Kirk's face onto it using a self hosted face-swap model. The image is processed locally and never leaves VoidWave's servers.

/kirkify servers, DMs and private channels

Kirkify an image (up to 10 MB). Processing is shared across the whole bot, so when another image is being kirkified you get a short "busy" message and are asked to retry.

Parameters
image The image to kirkify, uploaded as an attachment. Required.
hidden Show the result only to you. Optional.

Server control

admins only

Admins only. The server wide AI switch requires the Administrator permission.

/config ai toggle administrator

Switches automatic AI replies on or off for the whole server. When off, members can no longer trigger the AI by mentioning or replying, but they can still run /ai themselves.

Parameters
enabled True to allow replies, False to stop them.
