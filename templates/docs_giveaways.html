Giveaways run entirely in your server. Admins with Manage Server permission start them, members enter with a button, and winners are drawn at the deadline, announced in the channel, and DM'd. All commands require the Manage Server permission.

Starting a giveaway

admins only
/giveaway start manage server

Create a new giveaway. The bot posts an embed with an Enter button in the chosen channel. Members click to enter. At the deadline winners are picked at random, announced, and DM'd.

Parameters
prize What the winner(s) receive. Required.
duration How long it runs. Same formats as reminders: 1h, 2d, tomorrow 18:00, friday 20:00, 2026-09-20 12:00. Required.
winners How many winners to pick, from 1 to 50. Defaults to 1. Optional.
channel Channel to post in. Defaults to the channel you run the command in. Optional.
required_role Role members must have to enter. Optional.

Duration formats mirror the reminder system: 10m, 2h, 1h30m, 3d, tomorrow 18:00, friday 20:00, 2026-09-20 12:00, etc.

Entering is done by clicking the Enter button on the giveaway message. The button persists across bot restarts. If a required_role is set, only members with that role can enter.

Managing giveaways

admins only
/giveaway list manage server

List all active giveaways in the server with their entry counts and time remaining. Each entry shows the giveaway ID for use with other commands.

/giveaway end manage server

End a giveaway early and draw winners immediately. Pick the giveaway by ID (autocompletes from active giveaways).

Parameters
giveaway The giveaway to end. Type to autocomplete or paste the message ID. Required.
/giveaway reroll manage server

Pick new winners for an already ended giveaway. Previous winners are excluded so someone new gets a chance. Specify how many to reroll.

Parameters
giveaway The ended giveaway to reroll. Autocompletes from ended giveaways. Required.
winners How many new winners to pick, from 1 to 50. Defaults to 1. Optional.
/giveaway cancel manage server

Cancel a running giveaway without picking any winners. The embed updates to show it was cancelled.

Parameters
giveaway The active giveaway to cancel. Autocompletes from active giveaways. Required.

Winner selection

fair and random

When a giveaway ends (naturally or via /giveaway end), the bot picks the specified number of winners uniformly at random from all valid entries. Winners are announced in the giveaway channel, the embed updates with the winner list, and each winner receives a DM. If there are fewer entries than winners, all entrants win.

Rerolls work the same way but exclude anyone who already won that giveaway, so the new winners are different people.
