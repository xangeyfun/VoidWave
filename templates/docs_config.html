All configuration commands require the Administrator permission and work only in servers. The fastest way to get started is /config auto which creates channels, roles, and enables features in one go. For fine control use the individual commands below, or run /config view to see the current state and /config test to verify everything works.

Core commands

overview test help auto
/config view administrator

Shows an embed with the current configuration for leveling (channel, enabled state, vote announcements, AI replies, reward roles), QOTD (channel, enabled state, schedule, ping role, delete old), and AI replies.

/config test administrator

Runs a comprehensive health check on your leveling and QOTD setup. Reports missing channels, missing permissions, invalid times, unassignable roles, and more. Pass send_test:true to also send a test message into each configured channel and create a test thread for QOTD.

Parameters
send_test Also send test messages to verify delivery. Optional.
/config help administrator

Interactive help for configuration. Run without arguments for an overview with a dropdown to pick Leveling, QOTD, or AI. Pass a topic to jump straight to that section.

Parameters
topic leveling, qotd, or ai. Optional.
/config auto administrator

One shot setup. Creates a level-ups channel with locked down permissions (only the bot can send), a qotd channel with thread permissions, a QOTD Ping mentionable role, and enables both features. Anything already configured is left alone. Requires Manage Channels and Manage Roles.

Parameters
level Set up leveling. Defaults to true. Optional.
qotd Set up QOTD. Defaults to true. Optional.

Leveling

channel roles announcements
/config level set_channel administrator

Choose the channel where level up and rank up announcements are posted. The bot checks it can view and send messages there first.

Parameters
channel The text channel for announcements. Required.
/config level toggle_channel administrator

Enable or disable level up announcements. A channel must be set first. The bot verifies it can view the channel, send messages, and embed links before enabling.

Parameters
enabled true to announce, false to silence. Required.
/config level toggle_vote_announce administrator

Also announce when a member votes for the bot, posted to the same level up channel. Both this and the channel toggle must be on for announcements to show.

Parameters
enabled true to announce votes, false to skip them. Required.
/config level add_role administrator

Give a role at a specific level. The role must sit below the bot's highest role so it can be assigned. When a member reaches that level the role is granted automatically.

Parameters
level The level at which the role is granted. Required.
role The role to grant. Required.
/config level remove_role administrator

Remove a level reward role. The level picker autocompletes from levels that already have a role assigned.

Parameters
level The level whose reward role should be removed. Required.

Question of the Day

channel time role cleanup
/config qotd set_channel administrator

Set the channel where daily questions are posted. The bot checks it can view and send messages there first.

Parameters
channel The text channel for daily questions. Required.
/config qotd set_time administrator

Set the time of day the question posts in 24 hour format, and optionally a timezone. Changing the schedule resets today's state so the next question posts at the new time even if one already went out.

Parameters
time 24 hour HH:MM format, e.g. 18:30. Required.
timezone IANA timezone such as Europe/Amsterdam. Autocompletes as you type. Defaults to UTC. Optional.
/config qotd enable administrator

Turn the daily post on or off. A channel must be set first. The bot verifies it can view the channel, send and embed messages, and create and post in threads before enabling.

Parameters
enabled true to start posting, false to stop. Required.
/config qotd set_role administrator

Pick the role that is mentioned when a question posts. The role must be mentionable or the bot must have Mention Everyone permission. Use @everyone to ping the whole server.

Parameters
role The role to ping with the question. Required.
/config qotd delete_old administrator

When enabled, the previous question's message and thread are deleted right before the next one posts. This keeps the channel to just the latest question. Requires Manage Threads permission in the channel.

Parameters
enabled true to delete old questions, false to leave them up. Required.

AI replies

server wide toggle
/config ai toggle administrator

Switch automatic AI replies on or off for the whole server. When off, members can no longer trigger the AI by mentioning or replying, but they can still run /ai themselves.

Parameters
enabled true to allow replies, false to stop them. Required.
