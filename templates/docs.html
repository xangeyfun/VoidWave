Getting started

invite and basic setup

Add VoidWave: hit Add to Server on the homepage, pick your server, and authorize the requested permissions. VoidWave works in servers, DMs and private channels. Once added, VoidWave posts an automatic welcome message showing the quick start commands, and leveling runs immediately with no setup. Then run /config help for an overview of every configuration option, or /config auto for a guided setup in one command. The guided walkthrough on this site lives at /setup, or you can review your current settings with /config view at any time.

First commands to try

/help

Browse every command grouped by category. Not sure what something does? Start here.

/ping

Measure VoidWave's latency with a WebSocket ping.

/uptime

How long VoidWave has been online, along with useful links.

/github

Open the source code, report a bug, or request a feature.

/vote and /vote-remind

Vote to double your XP, and get a DM when you can vote again. More in Voting and boosts.

/feedback

Send a message straight to the developers. Good for bug reports and suggestions, and the reply is private.

/rate

Rate VoidWave right from Discord; feedback is optional.
