Preferences are personal and follow your account across every server and DM. They fill in the gaps when you skip optional command parameters, and any parameter still overrides them for that single command. Check yours with /prefs view.

Your preferences

/prefs
/prefs view servers, DMs and private channels

Shows every saved default: private replies, music source, autoplay on play, and reminder timezone, repeat, time of day and delivery channel. Only you can see the response.

/prefs private servers, DMs and private channels

Makes command replies private to you by default. Affects commands with a hidden: option, such as the fun commands, games, leveling, music, and moderation. Passing hidden: on a command still decides that command.

Parameters
enabled true for private-by-default, false for normal public replies. Required.
/prefs source servers, DMs and private channels

Default source for /music play and /music random. All is the default unless you save another value; when source: is left as All, your saved default is used instead.

Parameters
source All, YouTube, SoundCloud, or Spotify. Required.
/prefs autoplay servers, DMs and private channels

Turns autoplay on automatically whenever you start a fresh playback session through /music play or /music random. Fresh means nothing was playing and the queue was empty, so ending a session and starting a new one re-enables it for you.

Parameters
enabled true to auto-enable autoplay, false to leave it as-is. Required.

Reminder defaults

/remind defaults

Reminder defaults are saved through /remind defaults. They combine with /prefs so nearly every /remind create can be as short as /remind create water the plants when the rest is saved.

/remind defaults servers, DMs and private channels

View or set your default timezone, repeat, time of day, and delivery channel in one place. With no parameters it shows everything currently saved.

Parameters
timezone IANA timezone name used for the time of day and the reminder itself. Optional.
recurring Default repeat, e.g. daily, weekly, every 2h. Use none to clear it. Optional.
time Default time of day, e.g. 09:30. Used when you create a reminder without a time. Optional.
channel Default delivery channel. Reminders go here unless you pass channel:. Optional.
clear none (default), channel, time, or all. Clears the saved channel and/or time. Optional.

Falling back safely. If a saved default channel disappears, or you lose the permission to post there, reminders fall back to your DMs. If you leave that server entirely, clear it with /remind defaults clear:channel.
