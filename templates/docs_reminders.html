Reminders are personal. They belong to your Discord account and work in any server, DM, or private channel. By default they arrive in your DMs, but you can pick a server channel instead.

Creating a reminder

time message repeat
/remind create servers, DMs and private channels

Set a new reminder. The time parameter accepts natural language, durations, dates, and weekdays.

Parameters
time When to remind you. Examples: 10m, 2h, tomorrow 16:00, friday 18:30, 2026-09-20 12:00. Required.
message What to remind you about. Required.
recurring Repeat schedule. Presets: hourly, daily, weekly, biweekly, weekdays, weekends, monthly, yearly. Or custom like every 2h, every 1h30m, every 3d. Optional.
timezone Override your saved timezone for this reminder. Example: Europe/Amsterdam. Optional.
channel Deliver in a server channel instead of your DMs. The bot needs View Channel and Send Messages there. Optional.

Managing reminders

list edit delete
/remind list servers, DMs and private channels

Shows all your active reminders with their next trigger time, destination (DM or channel), and recurrence if any. Shows up to 25, with a note if you have more.

/remind delete servers, DMs and private channels

Delete a single reminder by its ID. The ID is shown in the list and when you create the reminder. Autocompletes from your active reminders.

Parameters
id The reminder ID. Required.
/remind edit servers, DMs and private channels

Change the message, trigger time, or timezone of an existing reminder. The recurrence pattern cannot be changed. Provide at least one of the optional parameters.

Parameters
id The reminder ID. Required.
message New reminder text. Optional.
time New trigger time in any accepted format. Optional.
timezone New timezone for this reminder. Optional.
/remind clear servers, DMs and private channels

Delete all your reminders at once. Asks for confirmation before removing everything, including recurring ones.

Timezone handling

your default zone

Reminders use your saved timezone by default, which starts as UTC. You can set a default with /remind timezone or override it per reminder with the timezone: parameter.

/remind timezone servers, DMs and private channels

View or set your default reminder timezone. Uses IANA timezone names like Europe/Amsterdam, America/New_York, Asia/Tokyo. Autocompletes as you type.

Parameters
timezone IANA timezone name. Leave empty to see your current setting. Optional.

Note on recurring reminders. When a recurring reminder fires, it reschedules itself to the next occurrence using the reminder timezone. If you change your default timezone later, existing recurring reminders keep their original timezone unless you edit them.

Delivery to channels

server channels

Pass the channel: parameter to deliver in a server text channel instead of your DMs. The bot checks that it can view and send messages in that channel before creating the reminder. If the channel is deleted or the bot loses permissions, the reminder falls back to DMs.
