VoidWave streams audio straight into your voice channel. When a track starts, a control embed appears in the text channel with buttons and a progress bar that updates live. Everyone in the voice channel can control the music.

Playing your first track

get started

Join any voice channel, then run /music play with a song. That is all it takes. The bot joins you, the track starts, and the interactive player appears in the channel you ran the command from. Every music command needs you to be in the same voice channel as the bot.

/music play server only

Start playback or add to the queue. If the search returns several candidates, an interactive picker lets you choose the right one. When nothing is picked within 30 seconds, it auto plays the best match. A source option limits the search: both (YouTube + SoundCloud, default), youtube, soundcloud, or spotify. You can also search a specific source with a prefix (spsearch:, ytsearch:, scsearch:).

Accepted inputs
Search terms Plain text like never gonna give you up or lofi jazz beats.
YouTube A video or playlist URL. Playlists are added to the queue as a group.
Spotify Track, album, playlist, or artist links, and full Spotify search (spsearch:). Spotify plays natively from the Spotify API, so tracks keep their real title, artist, and artwork.
SoundCloud A track or playlist URL, or search. SoundCloud tracks play natively from the source.
Parameters
query The song, link, or search term. Required.
hidden Keep the command response only to yourself. Optional.

The interactive player

the control embed

While music plays, a live embed sits in the channel where playback started. The progress bar updates in real time, and the buttons work for anyone in the voice channel. The embed's footer always shows the track's source (YouTube, Spotify or SoundCloud) and who added it; autoplay tracks are tagged as such.

Control What it does
🔀 Shuffle Randomize the upcoming queue.
⏮ Previous Play the most recent track again from history.
⏯ Play / Pause Pause and resume the current track.
⏭ Next Skip the current track, using the vote system unless you are the queue owner.
🔁 Loop Cycles through off, loop track, and loop queue.
👋 Leave Stop playback, clear the queue, and leave the voice channel.
📜 Queue Open the paginated queue with per track removal.
🎤 Live lyrics Toggle synced lyrics on the player embed itself.
📝 Lyrics Show the current track's lyrics in their own embed.
✨ Autoplay Toggle related tracks continuing when the queue empties.
🔊 Volume A dropdown that jumps to 10, 25, 50, 75 or 100 percent.

Lost the player? Run /music controller to post a fresh copy of the control embed into the current channel.

Commands

full reference
/music nowplaying server only

Show the current track with artwork, position, and length.

/music queue server only

Open the paginated queue view. You can clear the queue or remove specific tracks from the view's buttons, and page through with next and previous.

/music pause and /music resume server only

Pause or resume the current track.

/music skip server only

Skip the current track. The person who started the queue skips instantly. Everyone else votes: the required number is half of the non bot listeners in the channel, rounded down, plus one. Votes also count from the player's next button.

/music seek server only

Jump to a position in the current track. Accepts 1:30, 90 (seconds), or 2h5m style input.

Parameters
position Time to seek to. Required.
/music shuffle server only

Shuffle the upcoming queue, leaving the current track playing.

/music loop server only

Set the loop mode: off, track to repeat the current audio, or queue to repeat the whole list.

Parameters
mode off, track, or queue. Required.
/music volume server only

Set the playback volume. The value is clamped between 1 and 100.

Parameters
level Volume level from 1 to 100. Required.
/music lyrics server only

Fetch and display the current track's lyrics. When no track is playing it reports back.

/music lyricslive server only

Toggle synced, line by line lyrics on the player embed itself, so they follow the music in real time.

Parameters
mode on or off. Required.
/music autoplay server only

When on, related tracks keep playing once the queue runs out, so the music never stops until you leave.

Parameters
mode on or off. Required.
/music stop server only

Stop playback and clear the queue, staying in the voice channel.

/music disconnect server only

Stop playback, clear the queue, and leave the voice channel.

/music controller server only

Post a fresh interactive player embed into your channel if the original one has scrolled away.

Idle behaviour

what happens when nothing plays
Situation What VoidWave does
Queue finishes Waits 3 minutes, then leaves the channel and clears everything.
Voice channel empties Pauses playback immediately and starts the 3 minute leave countdown. If someone joins in time, music resumes by itself.
Autoplay running Related tracks keep the music going instead of stopping when the queue empties.

Playlists

your saved track lists

Note: playlists belong to your Discord account, not a server. They work in any server you play music in.

You can keep up to 25 playlists, each with up to 200 tracks and a name up to 32 characters. Track names are checked so the same song is not added twice to one playlist.

/music playlist create server only

Create a new playlist.

Parameters
name Name for the new playlist. Required.
/music playlist add server only

Add a track to a playlist. Accepts a URL or search term, exactly like /music play. If the search returns several candidates, the same picker lets you choose the right one, and auto adds the best match when nothing is picked within 30 seconds.

Parameters
name The playlist to add to. Autocompletes. Required.
query A track URL or search term. Required.
/music playlist remove server only

Remove a track from a playlist by its numbered position. Positions are shown by /music playlist list.

Parameters
name The playlist to edit. Required.
position Track number to remove. Required.
/music playlist list server only

List your playlists with track counts. Pass a name to open that playlist and page through its tracks.

Parameters
name Optional. When given, shows that playlist's tracks.
/music playlist play server only

Play a saved playlist in your voice channel. Tracks are resolved at play time, and any that can no longer be found are reported and skipped.

Parameters
name The playlist to play. Required.
/music playlist rename server only

Rename one of your playlists.

Parameters
name The current playlist name. Required.
new_name The new name. Required.
/music playlist delete server only

Delete a playlist along with all of its tracks.

Parameters
name The playlist to delete. Required.
