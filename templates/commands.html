Moderation

admins only
/moderation kick Kick a member from the server
/moderation ban Ban a member, optionally deleting their recent messages
/moderation unban Unban a user by their ID
/moderation timeout Timeout a member for a set duration
/moderation slowmode Set or clear slowmode on a channel
/moderation lock Lock a channel so members can't send messages
/moderation unlock Unlock a previously locked channel
/moderation role add Add a role to a member
/moderation role remove Remove a role from a member

The bot needs Kick Members, Ban Members, and Moderate Members in addition to Manage Messages for moderation to work. If it's missing one, the bot will tell you exactly which one to grant.

Admin configuration commands are available under /config. See the setup guide for details.
