Getting started

Setup Guide

Getting VoidWave running takes about 2 minutes. Follow these steps and you're good to go.

1

Invite the Bot

2 min

Click Add to Discord below, pick your server, and approve the permissions. Leveling starts working immediately.

If you ever re-add the bot, your server settings are saved.

Add to Discord
2

Quick Setup

easiest

Want everything set up in one command? Use /config auto to automatically create channels, roles, and enable features.

  • Set up everything - /config auto level:true qotd:true creates a level-ups channel, QOTD channel, QOTD Ping role, and enables both features.
  • Just leveling - /config auto level:true qotd:false only sets up level-up announcements.
  • Just QOTD - /config auto level:false qotd:true only sets up Question of the Day.

The bot needs Manage Channels and Manage Roles permissions for this to work. Skip to the next steps if you'd rather configure things manually.

3

Leveling System

out of the box

Works automatically. Members earn XP from messages and voice chat, and level up as they go. No extra setup needed for the basics.

  • Set a level up channel - /config level set_channel picks where level up announcements go. Without this, only the user sees their level up.
  • Toggle level up messages - /config level toggle_channel turns announcements on or off without losing your channel setting.
  • Auto roles - /config level add_role gives a role when someone hits a level. Add as many as you want. Use /config level remove_role to undo one.
4

Question of the Day

daily

Posts a daily question at 4:00 PM UTC to a channel you pick. It creates a thread for discussion that auto-archives after 24 hours.

  • Pick a channel - /config qotd set_channel #channel selects where the question and thread go.
  • Pick a role to ping - /config qotd set_role @role so people get notified. Use @everyone or a dedicated role.
  • Turn it on - /config qotd enable true starts the daily loop. Both a channel and role must be set first.
  • Disable it - /config qotd enable false stops it. Your settings are kept so you can re-enable later.
  • Clean up old posts - /config qotd delete_old true automatically deletes the previous day's QOTD message and thread when a new one is posted. Enabled by default.
5

Admin Info

admins only

All configuration is done through slash commands. Use /config view to see current settings or /config help for a full list of commands.

The bot also includes AI chat, fun commands, and more. Type /help to see everything available.

6

Moderation

admins only

All moderation commands live under /moderation. Anyone with Manage Messages can see the group; each command also checks for the specific permission it needs.

  • Remove members - /moderation kick and /moderation ban (with /moderation unban to reverse).
  • Timeout - /moderation timeout silences a member for minutes, hours, or days.
  • Channel control - /moderation slowmode, /moderation lock, and /moderation unlock.
  • Roles - /moderation role add and /moderation role remove.

For moderation to work, the bot needs Manage Messages, Kick Members, Ban Members, Moderate Members, Manage Channels, and Manage Roles. If it's missing one, the bot will tell you exactly which one to grant.
