Setup Guide

Getting Voidwave running on your server takes like 2 minutes. Here is how.

1. Invite the Bot

Click Add to Discord on the homepage, pick your server, and give it the permissions it asks for. That is it. The bot joins and starts working right away.

If you ever need to kick and readd it, just use the same link.

2. Leveling System

Leveling works out of the box. People earn XP by sending messages and hanging out in voice chat. XP gets calculated automatically and the bot tracks everything server wide.

You probably want to customize it a bit:

  • Set a level up channel - Use /config level set_channel to pick where level up messages show up. If you don't set one, nothing gets posted.
  • Toggle level up messages - /config level toggle_channel turns level up announcements on or off.
  • Auto roles - Use /config level add_role to give people a role when they hit a certain level. For example, give @Chatty at level 5. Use /config level remove_role to undo it.
  • Check your setup - /config view shows everything currently configured.

3. Question of the Day

QOTD posts a daily question at 4:00 PM to a channel you pick. It creates a thread so people can discuss without spamming the channel.

To set it up:

  • Pick a channel - /config qotd set_channel #your-channel
  • Pick a role to ping - /config qotd set_role @role so people know when a new question drops
  • Turn it on - /config qotd enable true
  • Change your mind? - Run /config qotd enable false to disable it

You need both a channel and a role set before you can enable QOTD.

4. AI Chat

Voidwave runs a local Llama 3.2 model for AI chat. You can talk to it in a few ways:

  • /ai - Send /ai your message here and get a response
  • Mention the bot - Ping @Voidwave with your question and it will answer
  • Reply to the bot - If the bot already said something, replying to its message continues the conversation

There is a 15 second cooldown per person so one user can't spam the AI. The model runs locally on the server, so it might be a bit slow sometimes.

5. Other Commands

Here are some fun ones to try:

/level Check your level and XP in the server
/profile View your global profile across all servers
/leaderboard See who is at the top. Sort by level, XP, or messages
/ping Check if the bot is alive, shows latency
/quote Get a random quote or quote of the day
/fact Random useless fact to impress your friends
/animal Cute dog, cat, duck, or fox pictures
/calc Quick math, safe to use
/flip Coin flip, good for arguments
/userinfo Shows details about a user like account age and roles
