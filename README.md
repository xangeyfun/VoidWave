*fast, simple, and actually fun to use.*

## ✨ Features

* XP & leveling system
* Global + server leaderboards
* AI chat powered by Llama 3.2
* Fast slash commands
* Shareable web profiles
* Auto role rewards
* Random utilities & fun commands
* Lightweight SQLite setup

> [!IMPORTANT]
> VoidWave is still actively developed.
> things might change, break, or randomly become better overnight.

## 🛠️ Tech Stack

| Part     | Tech                |
| -------- | ------------------- |
| Bot      | Python + discord.py |
| Website  | Flask               |
| Database | SQLite              |
| Frontend | Jinja + vanilla CSS |
| AI       | Ollama + Llama 3.2  |

> [!NOTE]
> The bot and website run separately, but both use the same database.
